# PopovWeb

Сайт Фёдора Попова: дизайн и разработка сайтов. RU/EN, тёмная тема с оранжевым акцентом и светлая с синим, тарифы в рублях и евро, интерактивный глобус и орбиты инструментов.

## Разработка

Нужен Node.js 22 или новее. Внешних npm-зависимостей нет.

```sh
npm start
npm run check
npm test
npm run build
```

Локальный адрес: http://localhost:4173/

Публикуется только `dist/`. Сборка использует явный список файлов, поэтому архивы, экспериментальные блоки и документы не попадают на публичный сайт.

## Netlify

Настройки сборки хранятся в `netlify.toml`: проверка JavaScript, тест вращения, затем статическая сборка в `dist/`. Ключи доступа не хранятся в репозитории.

## Основные файлы

- `index.html` — структура страницы.
- `styles.css`, `studio.css`, `fonts.css` — адаптивная вёрстка, темы и шрифты.
- `app.js`, `translations.js`, `studio-copy.js` — взаимодействия и перевод.
- `studio.js`, `rotor.js` — глобус, орбиты и выбор тарифа.
- `scripts/build.mjs` — production-сборка без сторонних зависимостей.
- `qa/rotor.test.mjs` — тесты поведения вращения.
- `design/studio-update.md` — описание текущей версии и источники иконок.

## Статус контента

Текущая версия предназначена для просмотра и доработки. Сохранены `noindex` и запрет индексации в `robots.txt`; перед публичным запуском их нужно пересмотреть. STILLA и LUMA явно обозначены как концепции, VELORA — шаблон в подготовке к запуску. Тарифы — стартовые предложения. Контактные кнопки открывают почту и сами не отправляют сообщения. Смена темы и языка сохраняется локально в браузере.

Шрифты поставляются с OFL-лицензиями в `assets/`, иконки Devicon — с лицензией в `assets/stack/DEVICON-LICENSE.txt`.
