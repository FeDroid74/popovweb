# PopovWeb

Основной домен: https://popovweb.com/ (Timeweb). Настройка публикации из `main`:
[timeweb-setup.md](timeweb-setup.md). Workflow подготовлен; отправка на сервер
включается через `TIMEWEB_DEPLOY_ENABLED` после установки SSH-ключа и настроек.

Сайт Федора Попова: дизайн и разработка сайтов. В репозитории две страницы:

- `/` (`index.html`) — основная версия.
- `/v3.html` — версия с интерактивным выбором услуги и просмотром работ.

Версия v2 удалена. Файлы `container-v2.css`, `header-v2.js`, `hero-grid-v2.js`, `contact-v2.js` и `ui-v2.*` — общие компоненты обеих сохранённых страниц; исторический суффикс не обозначает отдельную страницу.

Основная страница использует отдельные языковые URL: `/` и `/en/`. Язык определяется адресом, тема сохраняется в браузере. Цены показаны в рублях для RU и евро для EN. v3 сохраняет прежний переключатель внутри страницы.

Исходник основной страницы: `pages/home.html`. Файлы `index.html` и `en/index.html` генерируются командой `npm run build:pages`; не редактируйте их отдельно. `npm start` читает шаблон при запросе страницы. RU-словарь расположен в `translations.js`, общие тексты формы в `contact-copy.js`; двуязычные блоки используют data-ru/data-en.

Кейсы основной страницы описаны в `data/cases.mjs`: порядок, тексты RU/EN, подтверждённые сведения и ссылки. Изображения находятся в `assets/cases/`, размеры в `data/case-images.json`, происхождение в `assets/cases/SOURCES.txt`. `scripts/cases.mjs` создаёт карточки и модальные окна в обеих локализациях. В каждом окне показан один прокручиваемый макет. `case-dialog.js` управляет открытием, закрытием и сохранением позиции страницы; отдельные страницы кейсов больше не создаются. Чтобы добавить проект, внесите запись в данные и добавьте его изображения. VELORA остаётся в исходном HTML без изменений; вкладка «Продвижение» скрыта. В Git сохраняются используемые изображения и оригиналы для проверки; промежуточные материалы восстановления остаются локально.

Подготовленные пункты технического чек-листа и оставшиеся действия для домена: [launch-checklist.md](launch-checklist.md).

## Локальный запуск

Нужен Node.js 22 или новее.

```sh
npm ci
npm start
```

Основная версия: http://localhost:4173/ — v3: http://localhost:4173/v3.html.

## Проверка и сборка

```sh
npm run check
npm test
npm run build
```

`npm run build` собирает React/Radix UI через esbuild и копирует обе страницы с необходимыми ресурсами в `dist/`. Явный список в `scripts/build.mjs` исключает архивы, эксперименты и конфигурацию с секретами. `netlify.toml` задаёт те же проверки и публикацию каталога `dist/`.

## Основные файлы

- `index.html`, `app.js` — основная страница.
- `v3.html`, `v3.js`, `v3-base.js`, `v3.css`, `v3-base.css` — версия v3.
- `fonts.css`, `styles.css`, `studio.css`, `container-v2.css` — общие стили.
- `studio.js`, `rotor.js` — глобус и орбиты инструментов.
- `ui-v2.jsx` — Radix Select и Tooltip; `npm run build:ui` обновляет браузерный bundle.
- `contact-v2.js`, `contact-validation.js` — форма и проверка контактов.
- `server.mjs`, `contact-api.mjs` — локальный сервер и отправка заявок в Telegram.

## Форма и публикация

Для GitHub Pages подготовлен `.github/workflows/pages.yml`: после включения Pages с источником GitHub Actions каждый push в `main` запускает установку зависимостей, проверки, тесты, сборку и публикацию только `dist/`. Для приватного репозитория нужен тариф GitHub с поддержкой Pages; на бесплатном тарифе репозиторий должен быть публичным.

- Основная версия: https://fedroid74.github.io/popovweb/
- v3: https://fedroid74.github.io/popovweb/v3.html

Адреса начинают работать после успешного завершения workflow. Его также можно запустить вручную во вкладке Actions.

Ссылки открывают почту, WhatsApp и Telegram. Отправка формы требует настройки Telegram-бота: см. [contact-setup.md](contact-setup.md). Секреты задаются только на сервере; `.env` исключён из Git. Без настроенного бота форма сообщает об ошибке, а не показывает ложную отправку.

Статическая сборка не содержит серверного маршрута `/api/contact`. Для работающей формы на хостинге нужен отдельный серверный обработчик и переменные окружения.

GitHub Pages публикует основные RU/EN страницы с `index, follow`, canonical, hreflang и sitemap для `https://fedroid74.github.io/popovweb/`. Локальная сборка по умолчанию остаётся закрытой для индексации. При подключении собственного домена необходимо обновить `SITE_URL` и `SITE_BASE_PATH` в workflow.

Пока отдельный API не размещён, GitHub-сборка показывает прямую ссылку на Telegram вместо попытки отправки на несуществующий `/api/contact`. После размещения обработчика задайте repository variable `CONTACT_ENDPOINT` (полный HTTPS URL) и перезапустите публикацию. На сервере укажите `CONTACT_ALLOWED_ORIGINS=https://fedroid74.github.io` и секреты бота. Локальная форма продолжает использовать локальный обработчик.

Политика и отдельное согласие генерируются из `scripts/legal.mjs` в `documents/` в HTML и TXT, на русском и английском. Форма требует отдельного чекбокса; сервер проверяет версию согласия. Метрика пока не установлена. Перед её подключением и запуском приёма заявок нужно завершить выбор инфраструктуры обработки данных и актуализировать документы по фактической схеме.

`npm run images:optimize` создаёт WebP в `assets/optimized/` и манифест `data/optimized-images.json`. Оригиналы не меняются. Карточки используют небольшие превью с `srcset`; полный макет сохраняет исходные размеры и загружается только при открытии модального окна.

Шрифты поставляются с OFL-лицензиями в `assets/`, иконки — с лицензиями в `assets/stack/` и `assets/icons/`.
