# Заявки PopovWeb → Telegram

Формы основной версии и v3 отправляют POST на `/api/contact`. Сервер проверяет данные и передаёт сообщение через Telegram Bot API. Успех показывается только после подтверждения Telegram. При отсутствии настроек возвращается `503 not_configured`; заявка не сохраняется и не считается отправленной.

Интеграция использует метод [sendMessage из документации Telegram](https://core.telegram.org/bots/api#sendmessage).

Когда бот будет готов:

1. Создать `.env` рядом с `server.mjs` по примеру `.env.example`.
2. Внести `TELEGRAM_BOT_TOKEN` и числовой `TELEGRAM_CHAT_ID` получателя. Получатель должен предварительно открыть бота и нажать Start. Публичный username не заменяет числовой ID личного чата.
3. Перезапустить `npm start`.
4. Отправить одну тестовую заявку и проверить получение в Telegram.

Токен читает только сервер. `.env` исключён из Git, веб-сервер запрещает чтение скрытых файлов. Контактные данные не пишутся в логи или localStorage. Сервер ограничивает размер и частоту запросов. При неудаче введённые данные остаются в форме.

Это локальная интеграция: статическая сборка включает основную страницу и v3, но не серверный обработчик. Для публикации формы понадобится серверный маршрут на выбранном хостинге с переменными окружения. При работе за reverse proxy настроить ограничение запросов на уровне хостинга; текущий лимит использует адрес прямого соединения и не доверяет подставленным X-Forwarded-For.

Проверки без отправки сообщений: `node qa/contact.test.mjs`.

## Отдельный сервер для GitHub Pages

Сервер поддерживает CORS для точного списка `CONTACT_ALLOWED_ORIGINS` (через запятую). Для текущей страницы: `https://fedroid74.github.io`. Запросы с других origin отклоняются; OPTIONS разрешает только POST с JSON. CORS не заменяет серверные лимиты частоты запросов.

В GitHub → Settings → Secrets and variables → Actions → Variables задайте публичный `CONTACT_ENDPOINT` с HTTPS-адресом обработчика. Токен и ID чата задаются только на сервере, не в переменных статической сборки. Пустой `CONTACT_ENDPOINT` оставляет форму GitHub Pages отключённой с прямой ссылкой на Telegram, без запросов на несуществующий маршрут.

API принимает `consent: true` и `consentVersion: "2026-10-06"`; без них отклоняет заявку. Версия согласия и серверное время получения добавляются в уведомление. Локальный Node-обработчик не ведёт базу заявок: для запуска сбора данных оператором из РФ отдельно требуется определить инфраструктуру, локализацию, сроки хранения и основания передачи в сторонние сервисы. Наличие политики само по себе не заменяет эти настройки.
